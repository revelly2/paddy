=========================================================
PADDY - LOCAL SETUP & MIGRATION GUIDE
=========================================================
Follow these step-by-step instructions when moving this 
project to a new computer or setting it up from scratch.

---------------------------------------------------------
STEP 1: PREREQUISITES
---------------------------------------------------------
Ensure the new computer has the following installed:
1. Git (to clone the code)
2. Python (version 3.10 or newer)
3. Node.js (version 18 or newer)

---------------------------------------------------------
STEP 2: CLONE THE REPOSITORY
---------------------------------------------------------
Open your terminal (or Command Prompt/PowerShell) and run:
git clone https://github.com/revelly2/paddy.git
cd paddy

---------------------------------------------------------
STEP 3: SETUP THE BACKEND (PYTHON)
---------------------------------------------------------
1. In your terminal, navigate to the backend folder:
   cd backend

2. Create a virtual environment:
   Windows: py -m venv venv
   Mac/Linux: python3 -m venv venv

3. Activate the virtual environment:
   Windows: .\venv\Scripts\activate
   Mac/Linux: source venv/bin/activate

4. Install the backend dependencies:
   pip install -r requirements.txt

5. Set up Environment Variables:
   - Make a copy of the `backend/.env.example` file.
   - Rename the copy to exactly `.env`
   - Open `.env` and fill in your Supabase credentials (SUPABASE_URL, etc.)

---------------------------------------------------------
STEP 4: SETUP THE FRONTEND (REACT)
---------------------------------------------------------
1. Open a NEW terminal window and navigate to the frontend folder:
   cd frontend

2. Install the frontend dependencies:
   npm install

3. Set up Environment Variables:
   - Make a copy of the `frontend/.env.example` file.
   - Rename the copy to exactly `.env`
   - Open `.env` and fill in your Supabase credentials.
   - Make sure it has this line so it can talk to your local backend:
     VITE_API_BASE_URL=http://localhost:8000

---------------------------------------------------------
STEP 5: RUN THE PROJECT LOCALLY
---------------------------------------------------------
Every time you want to work on the app, you will need TWO 
terminal windows running at the same time.

Terminal 1 (Runs the Backend):
   cd backend
   .\venv\Scripts\activate
   uvicorn main:app --reload --port 8000

Terminal 2 (Runs the Frontend):
   cd frontend
   npm run dev

Once both are running, open your web browser and go to:
http://localhost:5173
